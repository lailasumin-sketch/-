# 가상 맛집·카페 30개

`mock-restaurants-cafes.xlsx`는 엑셀 파일이며 `mock-restaurants-cafes.csv`는 같은 자료의 UTF-8 BOM CSV입니다.

- 맛집 18개 + 카페 12개, 총 30개
- 엑셀 시트: 가상업소 30개 / 이용안내 / 항목 설명
- 메뉴·1인예산·동행·분위기·운영시간·휴무·체류시간·예약·반려견·주차 등 24개 항목
- 모든 업소명 앞에 [가상], 모든 행에 가상 테스트 데이터 표시
- 실제 주소·전화·예약 링크 없음. 권역 배치는 테스트를 위한 가정
- 자동 필터, 제목 고정, 가격 색상 구분 제공

이 데이터는 전부 창작했으며 공식 관광 자료나 실제 영업 정보가 아닙니다. 가상의 메뉴는 실제 알레르기 정보나 비건 여부를 보장하지 않습니다. 웹서비스의 맛집·카페 검색과 [가상] 코스 테스트에 연결했습니다. 실제 관광 후보와는 별도 데이터로 관리하며 가상 업소에는 지도·예약 링크를 제공하지 않습니다. 실제 여행 추천·길찾기·예약에 사용하지 마세요.
