# 의성 여행 자료 조사 현황

## 확인 범위

2026-10-24에 의성군 공식 홈페이지와 한국관광공사 대한민국 구석구석에 HTTPS 조회를 시도했으나 클라우드 프록시에서 `Tunnel connection failed: 403 Forbidden`으로 차단되었습니다. 이 날짜는 접속 시도일이며 원문 확인일이 아닙니다.

아래 35개 항목은 일반적으로 알려진 명칭을 기반으로 구성한 **원문 확인 전 조사 후보**입니다. 공식 자료에서 수집·선별을 완료한 35곳으로 설명하면 안 됩니다. 같은 마을·유적지 주변의 별도 시설도 포함되어 있어 독립적인 관광 권역 35개를 뜻하지 않습니다.

- 공식 원문 확인 완료: 0곳
- 식당: 검증된 개별 업소 없음. 장소 수에 포함하지 않음
- 숙박: 시설명 후보는 있지만 객실·운영·예약 미확인
- 축제: 확인한 개최 기간 없음. 일정을 만들어 넣지 않음
- 주소·좌표·영업시간·가격·교통시간: 미확인 값은 null로 보존
- 권역·동행 적합도·실내외·체류시간은 편집상 가정이며 공식 사실로 확인하지 않음
- 고운사·최치원문학관·금봉자연휴양림: 산불 영향과 현재 운영 여부 확인 전 자동 코스 제외. 휴관을 확정하는 표시는 아님

## 공식 자료 확인 대상

- https://www.usc.go.kr/ — 의성군. 장소별 상세 소개, 관광 안내, 공지·축제 일정 확인 필요
- https://korean.visitkorea.or.kr/ — 대한민국 구석구석. 장소별 상세 정보 확인 필요
- https://apis.data.go.kr/ — API 연동 시 공공데이터 서비스 확인 대상. 조회나 API 동작을 검증한 상태는 아님

위 주소는 **확인할 곳**이며 이미 읽은 출처가 아닙니다. 실제 근거 페이지를 읽은 후 `sourceUrl`에는 해당 상세 원문을, `sourceCheckedAt`에는 직접 확인한 날짜를 기록해야 합니다. 운영 여부는 별도 확인합니다. 사이트 공개 정보의 재사용 조건도 확인합니다.

## 검증·업데이트 절차

1. 네트워크 허용 설정을 적용한 후 공식 상세 원문을 열어 명칭·위치·운영 안내를 대조합니다. 현재 설정 초안에는 `www.usc.go.kr`, `usc.go.kr`, `korean.visitkorea.or.kr`, `apis.data.go.kr`만 추가했습니다. 저장이 곧 현재 실행 환경의 허용 적용을 뜻하지 않습니다.
2. `public/catalogue.json`에서 잘못된 후보는 삭제 또는 수정하고, 확인한 상세 원문·확인일을 기록합니다. 처음 화면 링크나 검색 결과 제목만으로 verified로 바꾸지 않습니다. 설명도 근거에 맞게 다시 씁니다.
3. 영업시간·휴무·가격·예약·주소는 확인한 항목만 기록합니다. 알 수 없는 항목은 null을 유지합니다. 현재 예약 확정·가격 필터·좌표 기반 경로 안내는 제공하지 않습니다.
4. 음식점은 개별 업소의 실제 영업·메뉴·주소·휴무를 확인해 추가해야 합니다. 단순 식당 검색 슬롯을 검증된 맛집으로 취급하지 않습니다.
5. 축제는 공식 개최 시작일·종료일·원문이 확인된 경우에만 `public/events.json`에 추가합니다. 이전 연도의 개최 기간을 다음 해에 재사용하지 않습니다.
6. 검토가 끝난 장소만 verification을 verified로 변경합니다. 보류 항목은 현재 방문 가능 여부를 확인한 뒤 hold를 해제합니다.
7. `npm run data:check`, `npm test`로 형식·추천 동작을 확인합니다. `npm run data:export`로 엑셀에서 열 수 있는 CSV를 다시 생성합니다. 자동 검사가 현장 사실 확인을 대신하지 않습니다.

## 배포 전 남은 일

공식 원문 검증, 실제 식당·일반 숙박업소 확보, 관광시설 운영·산불 복구 현황 확인, 좌표와 실제 교통 경로 연동, 접근성·입장 규정 확인, 데이터 재사용 조건 확인이 남았습니다. 현재 결과를 운영 가능한 최종 관광 안내로 홍보하지 않습니다.
