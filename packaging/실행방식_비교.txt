두 실행 방식 비교

공통: 같은 화면·CSV 내장 데이터·검색·필터·데이터 차트·시간순 추천·이유·요약을 사용합니다.
공통: 외부 지도/공식 홈페이지는 인터넷이 있어야 열립니다. 실제 운영·예약 정보는 없습니다.

A 실행하기.bat
- 포함된 x64/ARM64 Node.exe로 127.0.0.1의 사용 가능한 포트를 선택하는 로컬 서버 방식입니다.
- npm 설치나 사용자 명령 입력이 필요하지 않습니다. 브라우저 창 자동 열기를 시도합니다.
- 포트가 미리 정해져 있지 않고 USB 드라이브 문자를 하드코딩하지 않습니다.
- 서버 창을 닫으면 서비스가 종료됩니다.
- 서버 코드는 Linux에서 검증했으며, Windows BAT·Node.exe 실제 실행·브라우저 자동 열기는 미검증입니다.

B index.html
- 서버 없이 file://에서 열도록 classic JavaScript와 내장 데이터를 사용합니다.
- CSV/JSON fetch, ES module import, 외부 CDN·웹폰트 로딩이 없습니다.
- 로컬 글꼴은 CSS data URI에도 포함해 별도 폰트 파일 요청이 필요 없도록 했습니다.
- 클립보드가 제한되면 기존 텍스트 선택 복사 대안을 제공합니다.
- 관리형 브라우저가 file://를 차단하면 동작할 수 없습니다. 이 환경에서는 정책 차단으로 실행 미검증입니다.
- 기본 보안 정책을 해제하는 옵션을 사용하지 않았습니다. 차단 시 A 또는 PDF 발표자료를 사용하세요.

설치·업데이트·원본
- Windows 포터블 Node.js 공식 배포 파일과 라이선스를 포함합니다. 설치 작업은 하지 않습니다.
- 원본 CSV는 data에 보존하고, 배포 앱은 빌드 시 내장한 데이터를 읽습니다.
- source는 개발 원본입니다. 심사위원이 source 안의 npm 명령을 실행할 필요는 없습니다.
