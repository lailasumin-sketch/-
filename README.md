# 의동이 픽

취향은 내가, 의성 여행은 의동이가. 기간·동행·관심사·권역·실내외·속도를 반영하는 의성 여행 후보 코스 프로토타입입니다.

## 노트북에서 실행

Node.js 20 이상을 설치하고 ZIP 압축을 푼 폴더(`package.json`이 있는 위치)에서 실행합니다. 추가 npm 의존성 설치는 필요 없습니다.

```sh
npm start
```

브라우저 주소창에 `http://localhost:3000`을 입력합니다. 기존 서버가 켜져 있다면 명령어 창에서 Ctrl+C를 누른 후 다시 `npm start`를 실행합니다. 포트는 `PORT` 환경변수로 변경할 수 있습니다.

## 0.2 변경 사항

- 장소 조사 후보 35곳을 별도 JSON으로 분리. 검색·분류·권역 필터와 확인 상태 표시
- 가족·연인·혼자·친구의 취향, 실내외, 추정 권역, 여행 속도에 따라 후보 점수와 구성 변경
- 같은 장소·시설군 반복 방지, 체류 가정과 이동 여유를 고려한 방문 수 제한
- 여러 날의 코스에는 요청한 관심사를 분산 배치
- 문장에서 제외 조건, 실내·야외, 여행 속도, 권역, 명시적 날짜 추출
- 방문일과 겹치는 확인된 축제만 별도 표시하는 구조. 현재 확인된 행사는 없음
- 자료가 없으면 임의 장소·식당·호텔을 만들지 않고 부족 항목과 검색 과제를 표시
- 원문 확인 전 후보를 제외하는 선택 제공. 현재 해제 시 검증된 관광지 자료가 없어 빈 결과가 정상

## 중요한 자료 상태

**공식 원문 확인 0곳 / 조사 후보 35곳.** 클라우드에서 의성군과 대한민국 구석구석 원문 조회가 네트워크 정책으로 차단되어 정식 수집·검증이 끝나지 않았습니다. [조사 현황과 후보 목록](data/RESEARCH.md), [엑셀용 CSV](data/research-candidates.csv)를 확인하세요. 공식 홈페이지 링크는 조사 대상이며 이미 확인한 상세 출처가 아닙니다.

음식점은 검증된 개별 업소가 없어 지역별 검색 안내만 제공합니다. 숙박 후보의 운영·예약은 미확인이고, 보통 숙소는 검색 안내입니다. 날짜별 영업시간·가격·최신 축제·실제 이동시간·예약·날씨·외부 AI에 연결되지 않았습니다. 권역·동행 적합도·실내외·체류시간은 편집상 가정입니다. 산불 영향 등 운영 여부의 우선 확인이 필요한 후보는 자동 배치에서 보류합니다. 자료 부족을 감추기 위해 빈 일정을 임의 장소로 채우지 않습니다.

## 자료 관리와 검증

```sh
npm test
npm run data:check
npm run data:export
```

- `public/catalogue.json`: 조사 후보와 필드별 미확인 값
- `public/events.json`: 공식 개최 기간이 확인된 행사 추가 위치
- `data/RESEARCH.md`: 원문 접근 결과·정리 목록·후속 검증 절차
- `data/research-candidates.csv`: 후보와 출처 확인 상태를 담은 엑셀용 파일

확인한 원문 상세 URL·확인일을 기록한 후에만 자료를 verified로 바꾸세요. 목록·메인 화면 URL만으로 근거를 대신하지 마세요. `npm run data:check`는 자료 형식 검사이며 사실 검증이 아닙니다.

Google Fonts 연결 실패 시 시스템 글꼴로 표시됩니다. 메인 이미지는 로컬 SVG 일러스트입니다. 공식 기관 운영 서비스가 아닙니다. GitHub에 업로드하는 것과 웹서비스 공개 배포는 별개입니다.
