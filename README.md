# 의동이 픽

취향은 내가, 의성 여행은 의동이가. 클릭 또는 한국어 문장으로 기간·동행·관심사를 선택하고 의성 여행 참고 일정을 만드는 반응형 웹 프로토타입입니다.

## 실행

Node.js 20 이상에서 추가 의존성 설치 없이 실행합니다.

```sh
cd /workspace/-
npm start
```

기본 포트는 3000이며 `PORT` 환경변수로 변경할 수 있습니다. `npm test`로 추천·문장 분석 검증을 실행합니다.

## 기능과 범위

- 반나절부터 2박 3일까지, 동행·관심사·교통수단·출발 날짜 선택
- 한국어 키워드 추출 후 선택 조건에 반영, 날짜는 여행 라벨로 표시
- 일정 추천, 장소 검색 링크, 일정 클립보드 복사
- 짧은 일정에서 제외된 항목, 대중교통 확인 사항 안내
- 모바일 대응, 키보드 접근, 선택 상태와 상태 메시지 제공

실시간 AI, 길찾기, 축제·영업·예약·날씨 데이터와 연결되지 않은 데모입니다. 장소 정보는 일반적인 참고 자료이며 영업점 추천이나 예약을 보장하지 않습니다. 체험과 숙박은 업체 확인을 위한 탐색 항목입니다. 축제는 개최를 확정하지 않습니다. 상용 서비스에는 공식 관광 데이터, 검증된 업소·체험·숙박 목록, 날짜별 운영시간, 교통 경로 및 예약 연동이 필요합니다. 자연어는 키워드 기반으로 부정 표현과 복잡한 문맥을 완전히 해석하지 못합니다.

외부 Google Fonts를 사용할 수 없는 환경에서는 시스템 글꼴로 표시됩니다. 메인 이미지는 여행의 분위기를 담은 로컬 SVG 일러스트입니다. 공식 기관 운영 서비스가 아닙니다.
