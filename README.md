# 의동이 픽

취향은 내가, 의성 여행은 의동이가. 기간·동행·관심사·권역·실내외·속도를 반영하는 의성 여행 후보 코스 프로토타입입니다.

## 노트북에서 실행

Node.js 20 이상을 설치하고 ZIP 압축을 푼 폴더(`package.json`이 있는 위치)에서 실행합니다. 추가 npm 의존성 설치는 필요 없습니다.

```sh
npm start
```

브라우저 주소창에 `http://localhost:3000`을 입력합니다. 기존 서버가 켜져 있다면 명령어 창에서 Ctrl+C를 누른 후 다시 `npm start`를 실행합니다. 포트는 `PORT` 환경변수로 변경할 수 있습니다.

## 0.3 가상 맛집·카페 연동

- 원본 엑셀과 동일한 CSV의 맛집 18개·카페 12개를 `public/dining.json`으로 변환해 검색·일정에 연결
- 관심사에 카페 추가. 목록 검색창에서 `맛집`, `카페`, `마늘`, `조용한 카페 1만원 이하` 또는 업소명 검색
- 분류·권역·1인 예산·주차·조용한 분위기 필터, 업소 선택 후 당일 코스 테스트
- 문장 입력 예: `연인과 당일치기 맛집과 조용한 카페, 1인 15000원 이하, 주차 가능`
- 메뉴·가격·동행·체류시간과 가상 영업시간·휴무·브레이크타임을 일정에 반영
- 모든 가상 업소에 [가상] 표시. 가짜 지도·전화·예약 링크를 만들지 않음
- 관광 미확인 후보 포함 여부와 별개로 가상 업소 테스트를 켜고 끌 수 있음

원본 엑셀의 이용안내·항목 설명에 따라 모든 업소명과 값은 창작 데이터입니다. **실제 여행의 식당·카페 정보로 사용할 수 없습니다.** 가상의 읍면 배치는 실제 주소나 이동 동선이 아닙니다. 총 여행 예산이 아닌 업소별 1인 예산 상한을 필터링합니다. 실제 음식점 정보나 실시간 API가 연동된 것은 아닙니다.

### 가상 데이터 갱신

엑셀 파일을 편집한 경우, `가상업소 30개` 시트의 4행 헤더와 5행 이후 업소 데이터를 같은 열 순서의 UTF-8 CSV로 저장하고 `data/mock/mock-restaurants-cafes.csv`를 교체합니다. 첫 세 줄 제목은 CSV에 포함하지 않습니다. 이후 아래 명령을 실행하고 서버를 재시작·브라우저를 새로고침합니다.

```sh
npm run data:dining
npm run data:check
npm test
```

웹사이트는 엑셀 바이너리를 직접 읽거나 업로드·실시간 감시하지 않습니다. 저장된 CSV를 설치 의존성 없이 변환한 JSON을 읽습니다. `data:check`는 CSV와 웹 데이터의 일치 여부를 검사합니다.

## 0.2 변경 사항

- 장소 조사 후보 35곳을 별도 JSON으로 분리. 검색·분류·권역 필터와 확인 상태 표시
- 가족·연인·혼자·친구의 취향, 실내외, 추정 권역, 여행 속도에 따라 후보 점수와 구성 변경
- 같은 장소·시설군 반복 방지, 체류 가정과 이동 여유를 고려한 방문 수 제한
- 여러 날의 코스에는 요청한 관심사를 분산 배치
- 문장에서 제외 조건, 실내·야외, 여행 속도, 권역, 명시적 날짜 추출
- 방문일과 겹치는 확인된 축제만 별도 표시하는 구조. 현재 확인된 행사는 없음
- 자료가 없으면 임의 장소·식당·호텔을 만들지 않고 부족 항목과 검색 과제를 표시
- 원문 확인 전 후보를 제외하는 선택 제공. 현재 해제 시 검증된 관광지 자료가 없어 빈 결과가 정상

## 중요한 자료 상태

**공식 원문 확인 0곳 / 조사 후보 35곳.** 클라우드에서 의성군과 대한민국 구석구석 원문 조회가 네트워크 정책으로 차단되어 정식 수집·검증이 끝나지 않았습니다. [조사 현황과 후보 목록](data/RESEARCH.md), [엑셀용 CSV](data/research-candidates.csv)를 확인하세요. 공식 홈페이지 링크는 조사 대상이며 이미 확인한 상세 출처가 아닙니다.

실제 음식점은 검증된 개별 업소가 없습니다. 가상 데이터 모드를 켜면 창작 맛집·카페로 테스트하고, 끄면 실제 업소를 직접 확인하는 검색 안내를 제공합니다. 숙박 후보의 운영·예약은 미확인이고, 보통 숙소는 검색 안내입니다. 날짜별 영업시간·가격·최신 축제·실제 이동시간·예약·날씨·외부 AI에 연결되지 않았습니다. 권역·동행 적합도·실내외·체류시간은 편집상 가정입니다. 산불 영향 등 운영 여부의 우선 확인이 필요한 후보는 자동 배치에서 보류합니다. 자료 부족을 감추기 위해 빈 일정을 임의 장소로 채우지 않습니다.

## 자료 관리와 검증

```sh
npm test
npm run data:check
npm run data:export
```

- `public/catalogue.json`: 조사 후보와 필드별 미확인 값
- `public/events.json`: 공식 개최 기간이 확인된 행사 추가 위치
- `data/RESEARCH.md`: 원문 접근 결과·정리 목록·후속 검증 절차
- `data/research-candidates.csv`: 후보와 출처 확인 상태를 담은 엑셀용 파일

확인한 원문 상세 URL·확인일을 기록한 후에만 자료를 verified로 바꾸세요. 목록·메인 화면 URL만으로 근거를 대신하지 마세요. `npm run data:check`는 자료 형식 검사이며 사실 검증이 아닙니다.

Google Fonts 연결 실패 시 시스템 글꼴로 표시됩니다. 메인 이미지는 로컬 SVG 일러스트입니다. 공식 기관 운영 서비스가 아닙니다. GitHub에 업로드하는 것과 웹서비스 공개 배포는 별개입니다.

## Vercel 체험용 배포

저장소 루트의 `vercel.json`에 정적 웹 배포 설정을 저장했습니다. 이 설정은 실제 음식점/API 서비스가 아닌 현재 체험용 화면을 배포합니다.

1. Vercel에서 GitHub 저장소 `lailasumin-sketch/-`를 Import 합니다.
2. Project Name을 `uidongi-pick` 등 영문 이름으로 지정합니다.
3. **Root Directory는 기본값 `.`(저장소 루트)** 로 둡니다. 이전 안내의 `public` 대신 루트를 선택하면 저장된 `vercel.json` 설정이 적용됩니다.
4. Framework Preset은 Other, 설치는 생략, Build Command는 `npm run data:check`, Output Directory는 `public`입니다. 저장된 설정을 사용하면 해당 값을 수동으로 반복 입력할 필요가 없습니다.
5. Deploy를 누르고 완료된 주소에서 카페 12곳·맛집 18곳 검색과 코스 추천을 확인합니다.

`public`만 웹사이트 파일로 제공하며 `server.js` 실행이나 비밀키는 현재 체험 버전에 필요하지 않습니다. 로컬의 `npm start` 실행 방식은 그대로 사용할 수 있습니다. `.vercel/` 연결 설정과 환경 변수 파일은 Git에 올리지 않도록 제외했습니다.

CLI로 배포하는 경우 Vercel 계정 로그인과 정확한 프로젝트 연결을 먼저 확인해야 합니다. GitHub 업로드와 Vercel 배포 완료는 서로 다르며, 배포 URL과 READY 상태를 확인하기 전에는 공개되었다고 판단하지 않습니다.
