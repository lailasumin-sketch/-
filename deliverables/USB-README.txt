의동이 PICK — USB 심사용 체험판
취향은 내가, 의성 여행은 의동이가

[먼저 확인]
ZIP 파일이라면 반드시 전체 압축을 푼 뒤 실행하세요.
USB_최종제출 폴더 전체를 USB에 복사하세요. 파일 몇 개만 복사하면 안 됩니다.
Windows 10/11의 x64·ARM64용 구성을 준비했습니다. 32비트 Windows는 지원하지 않습니다.
실제 Windows PC의 더블클릭 실행은 미검증입니다. 아래 검증 범위를 읽어 주세요.

[A. 기본 실행]
1. 실행하기.bat를 더블클릭합니다.
2. 잠시 기다리면 빈 로컬 포트를 골라 기본 브라우저를 여는 구성입니다.
3. 브라우저가 안 열리면 검은 창의 http://127.0.0.1:숫자/ 주소를 직접 여세요.
4. 사용하는 동안 검은 창을 열어 두세요. 종료하려면 창을 닫으세요.
포터블 Node.js가 node 폴더에 포함되어 있습니다. Node.js·npm·VS Code 설치나 명령 입력이 필요 없습니다.
node 폴더와 server 폴더를 삭제하거나 이동하지 마세요.

[B. 보조 실행]
index.html을 더블클릭합니다. Edge 또는 Chrome 등 최신 브라우저를 권장합니다.
서버 없이 열 수 있도록 데이터를 JavaScript에 내장하고 모듈 스크립트를 단일 스크립트로 묶었습니다.
인터넷 없이 검색·필터·차트·추천·일정 요약을 사용할 수 있도록 구성했습니다.
이 제작 환경의 관리 브라우저는 file:// 자체를 정책으로 차단하여 직접 실행은 미검증입니다.
기관 PC에서도 파일 열기를 차단하면 A 방식을 사용하세요. 보안 정책을 해제하거나 우회하지 마세요.

[간단한 시연]
1. 여행 기간, 가족/연인 등 동행, 관심사를 선택합니다.
2. 시작시간과 전체 활동시간을 입력하고 추천받기를 누릅니다.
3. 장소 아래 초록 체크로 추천 이유를 확인합니다.
4. 전체 관광정보 검색·필터를 펼친 뒤 '카페' 또는 '맛집'을 입력합니다.
5. 권역·예산을 바꾸면 목록과 아래 데이터 차트가 함께 바뀝니다.
입력 예: 가족과 당일치기 맛집 카페 볼거리, 오전 9시30분부터 총 6시간

[데이터와 한계]
관광 조사 후보 35곳, 가상 맛집 18곳, 가상 카페 12곳입니다.
현재 CSV를 사용하고 가상 표시를 유지하기로 사용자 확인을 받았습니다.
주최 측이 제공한 실제 CSV로 확인된 자료는 없습니다. 실제 업소·실시간 AI·지도·예약 연동이 아닙니다.
차트는 검색된 레코드 수이며 방문 실적·매출 통계가 아닙니다.
이동시간표가 없어 미확인 구간은 숫자를 만들지 않습니다. 이후 시각은 임시 최소 시각입니다.
직접 입력한 이동 여유는 시간 예산에 포함하지만 실제 도로 이동시간은 아닙니다.
외부 지도·공식 홈페이지는 인터넷 연결이 필요합니다. 핵심 기능은 외부 API를 요청하지 않습니다.
일정 복사가 막히면 화면에 제공되는 텍스트를 직접 선택해 복사하세요.
내장 데이터 방식이므로 CSV를 수정해도 즉시 반영되지 않습니다. 개발자가 다시 빌드해야 합니다.

[발표자료]
발표자료/의동이_PICK_5분발표.pdf : 5장, 브라우저로 열 수 있습니다.
발표자료/의동이_PICK_5분발표.pptx : 편집용 PowerPoint, 발표자 노트 포함.
발표자료/5분_발표대본.txt : 약 5분 발표용 대본. 실제 발화 시간은 연습해 조정하세요.
실제 화면 캡처도 발표자료 폴더에 있습니다.

[검증 범위]
확인: 공식 Node.js 체크섬·PE 아키텍처, BAT 상대경로 정적 검사,
Linux에서 서버의 빈 포트·오류 처리·경로 이동, 인터넷 차단 후 검색·필터·차트·추천·모바일.
미검증: 실제 Windows 더블클릭, Node 미설치 Windows PC, 기본 브라우저 자동 열기,
실제 USB 드라이브 문자 변경, 관리 정책으로 차단된 file:// 직접 실행.
제출 전 실제 심사 Windows PC에서 두 실행 방식을 확인해 주세요.
A와 B가 모두 기관 보안 정책에 막히면 발표자료 PDF와 실제 화면 캡처를 이용하세요.
자세한 결과는 검증결과.json, 실행방식_비교.txt, 개발_검증보고서.md에 있습니다.
